# App Store Connect screenshots

The files in these folders are ready for the App Store Connect screenshot slots:

- `iphone-6.5`: 2688 × 1242 px (landscape, 6.5-inch display)
- `ipad-13`: 2064 × 2752 px (portrait, 12.9-inch or 13-inch display)

Each set contains five screenshots in suggested upload order:

1. Create a model
2. Edit a generated model
3. Explore community models
4. Build with instructions
5. Convert a GLB model

The public privacy policy URL is `https://brickbuilder.ai/privacy` after the frontend is deployed.
